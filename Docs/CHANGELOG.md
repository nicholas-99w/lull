# Changelog

## 1.0.0 build 13: first public release

Lull's first public release: scheduled device-free hours for school Macs,
managed with Jamf Pro.

- Schedules in the school's time zone: school nights, weekends, windows past
  midnight, holidays and device-free days, with daylight saving handled.
- Warning cards before downtime, a final countdown and an optional snooze.
- A branded lock screen on every display, in light and dark mode.
- Trusted time that ignores clock and time zone changes and works offline.
- A lock screen that comes back within seconds if it's quit, killed or
  unloaded, and never traps anyone: Shut Down, Sleep and a time-limited
  admin override.
- Exemptions for staff and admin accounts.
- A signed and notarised installer, a Jamf Pro custom schema, a login items
  profile and extension attributes for monitoring.

See the [Deployment guide](DEPLOYMENT.md) to get started.
